# tristan_coldefy.com

**tristan_coldefy.com** est un projet de **site vitrine** personnel, encore en cours de construction.

## Structure
- **Frontend** : pour l’instant **vide** (sera rempli au fur et à mesure).
- **Backend** : gère une **base de données de comptes** (création, connexion, vérification, gestion des emails / sessions, etc.).

## Statut
Projet en cours — le contenu et les fonctionnalités évoluent régulièrement.
